# Security and privacy

Please do not include prompts, local state databases, terminal screenshots, access tokens, internal repository names, or full home-directory paths in public bug reports.

The default `safe` title mode does not use raw prompt text. The optional `prompt` mode applies best-effort filtering, but it cannot reliably classify every secret or confidential phrase.

The project reads agent state databases only in SQLite read-only mode and does not perform network requests.

Report security issues privately to the repository maintainer instead of opening a public issue.
